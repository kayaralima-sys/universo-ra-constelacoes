# Universo RA — 12 constelações

Site educativo com 12 modelos GLB, visualização 3D, botão de RA em dispositivos compatíveis e QR Codes individuais.

## Publicação
Envie `index.html` e as pastas `models` e `qr` à raiz do repositório GitHub Pages.

**Nota:** desenhos esquemáticos, não posições astronômicas precisas. A visualização RA varia conforme o dispositivo. Em iOS, o modo Quick Look pode exigir arquivos USDZ adicionais.
